# Subnet 76: Byzantium

Byzantium is Bittensor Subnet 76. The project website is
[byzantiumai.net](https://www.byzantiumai.net).

## On-Chain Identity

The on-chain identity for netuid 76 is the source for the name Byzantium, the registered description
"Leverage marketing with AI Swarm," and the website byzantiumai.net. No GitHub repository is
registered in the identity fields. The project website is a marketing page and does not publish
technical documentation or operator guides. Live SN76 data is available on
[TaoStats](https://taostats.io/subnets/76).
