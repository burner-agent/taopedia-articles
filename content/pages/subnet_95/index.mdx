# Subnet 95: Actual

Actual is Bittensor Subnet 95.

## What Actual Provides

The on-chain description identifies SN95 as a heterogeneous inference network. In that context,
heterogeneous inference means serving AI model inference across varied hardware types, model
architectures, or execution backends rather than a single uniform stack. The additional identity
field registered on-chain reads "Inference time from machines running Actual," indicating the
network is focused on inference compute rather than training.

The public website at [actual.inc](https://actual.inc) and the
[actual-computer](https://github.com/actual-computer) GitHub organization describe Actual Computer
Inc. as a company building AI infrastructure at the intersection of systems engineering and machine
learning. The subnet's GitHub repository is registered on-chain as
`actual-computer/actual-subnet-95`, but that repository is not publicly accessible. Because the
operator has not published the validator code, miner task specification, or scoring function, those
details are not described here.

## On-Chain Identity

The on-chain identity for netuid 95 registers the name Actual, the description "Heterogeneous
inference network by Actual Computer Inc.", and the website actual.inc. The GitHub repository field
lists `actual-computer/actual-subnet-95`, which is not publicly accessible. Readers who want to
verify the current chain state can check the
[actual-computer GitHub organization](https://github.com/actual-computer) for any newly public
repositories. Live SN95 data is available on [TaoStats](https://taostats.io/subnets/95).
